# 中枢界面统一改版

改版前代码检查点：`b24b794`。此次只调整自定义界面的表现，不改已有变量、存档数据、任命效果、扣费及确认条件。

## 当前实现

- 八个 GUI 文件（共十个窗口）共用不透明深色底板、标题区、内容分区及底栏。青绿细边框保留群星风格，地图不再透过正文。
- 首页缩小为 880×560，移除大卡片外壳，以两列紧凑按钮显示功能名：左侧建设与军备，右侧治理与飞升。用途说明复用已有悬浮提示，无提示的入口补充提示。灵能的可解锁、已完成、未满足条件选项共用最后一个位置。快捷开关集中在入口下方；关闭状态改为灰色。底部只保留关闭，不再放首页返回首页按钮。
- 军事、星球与经济、巨构与资源三页增加分组标题及独立数值行底板，保留原有档位、加减、单项重置和即时数值显示。
- 内阁页区分日常设置与维护工具。内阁流程、同化、飞升槽位、巨构工程署、基地清理及区划扩容沿用共同的左侧说明／右侧操作布局。

按用户反馈精简常驻文字：删除顶部操作介绍、卡片副说明及底部重复规则。军事数值按钮的悬浮提示包含加减、零下限、重置及相应项目规则；内阁协议的悬浮提示包含具体加成。同化首页仅显示来源与目标，飞升首页仅显示当前与目标格数，操作规则放到选择、调整和补齐按钮提示中。巨构类型选择及基地选择页缩短为一句选择提示，详细范围放入悬浮提示。费用预览、动态状态、保护失败原因、不可逆操作的确认信息完整保留。

飞升目标提供 ±1、±2、±4、±8、±16 五档，按档位从小到大排列，边界为 1～4096。调整不立即解锁，仍需点击“补齐至目标”。GUI 移除操作列表中的重复返回入口，使用底栏返回首页，全部档位与补齐操作保持在同一页。已有目标与已解锁数量沿用。

首页卡片通过原生 `option.custom_gui` 定位，保留原选项名称、条件、提示和效果。卡片条目使用一像素高度，并在卡片坐标中扣除前面条目的累计高度；底栏保持现有的零高度定位。跳转消费当前事件后再打开下一页。没有通过 `effectButtonType` 打开新可见窗口。原生 `EVENT_DIPLO.option_list`、说明文字及完整滚动条绑定均保留。

2026-11-08 首次实机截图显示标题和快捷开关正常，但全部卡片和底栏消失，日志未发现对应 GUI 绑定错误。首版将首页所有列表条目设为零高度，列表没有实际内容高度，是当前优先修复的嫌疑；改用军事底栏已采用的一像素条目，并增加累计布局与非零高度检查。该修正仍需实机复测，不能视为已经确认根因。

本版继续使用已验证的原生返回和分页导航。此前讨论的常驻跨模块侧栏尚未实现；需单独验证原生事件列表中导航与长候选列表共存的行为。

### 2026-11-08 飞升入口闪退修复

15:30:25 的日志明确报告请求不存在的 `auto_qol_ascension_gui_unlock_tt_window`，随后在备用窗口中找不到必需原生控件。精简文字时，`clone_visible` 的本地化映射循环复用了保存 GUI 命名空间的 `target` 变量，导致生成窗口引用被提示词键覆盖，也会污染后续事件的路由命名空间。同化与飞升生成器共用该逻辑，因此同时修复并重新生成两个工作流。

修复使用独立的 `source_key`、`display_key` 变量。新增独立预期的窗口／事件命名空间回归检查，以及发布构建中的所有自有 `custom_gui`、`custom_gui_option` 引用校验；缺失定义会中止打包。代码与构建检查通过不代表游戏内点击已复测通过。

## 生成与打包

共享纹理由 `python tools/console_theme.py` 确定性生成，仅此命令需要 Pillow。三张 DDS 与 `interface/auto_qol_console.gfx` 随源码提交，常规构建不需要 Pillow。生成器共用 `console_theme.py`，重新生成不会丢失样式。

依次运行现有 GUI 生成器：`build_military_gui.py`、`build_council_gui.py`、`build_hub_gui.py`、`build_species_ascension_gui.py`、`build_megastructure_office.py`、`build_starbase_clear.py`、`build_district_expansion.py`。文件均在 `tools/` 下。

公开及本地发布构建均包含共享 GFX 和 DDS；构建校验会拒绝缺失纹理。现有游戏目录和发布成品目录不自动覆盖。

## 游戏内验收

静态检查不代替引擎渲染验证。新增 GFX、DDS 和 GUI 模板后完整重启游戏，再检查：

1. 首页八张卡片、说明、快捷开关与底栏是否完整显示。特别检查一像素条目的子控件是否被裁切，以及灵能三种状态是否使用同一位置。
2. 各入口单击跳转，返回首页、右上角关闭、Esc、关闭重开；确认不叠窗。
3. 数值加减、归零、自动化比例上限与存档已有加成是否保持；数值文本是否即时刷新。
4. 内阁十位候选、十二行名册、分页和原生滚动；说明、设置与维护按钮是否重叠。
5. 同化和灵能槽位确认、巨构费用预览、基地强拆保护及区划扩容流程。
6. 默认和用户常用 UI 缩放下的文字换行、边框、窗口边界和按钮命中区域。
