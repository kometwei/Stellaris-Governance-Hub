# 名单文本输入调研（本机4.5.2）

结论：原版界面有可编辑文本框；尚未找到自定义按钮/事件脚本读取任意输入文本、
据其筛选舰队名称的明确接口。这不是“已证明不可实现”，也不是搜索功能已可用。
本轮只做源码与文档检查，未修改原版界面或当前整理插件，未做游戏内输入回传实验。

## 本机证据

游戏目录：`D:/Steam/steamapps/common/Stellaris`。

- `interface/rename_dialog.gui:43`：原版通用改名窗口`editBoxType`，控件名`editbox`。
- `interface/databank_window.gui:56`：原版资料库搜索框`editBoxType`，控件名`filter_edit`。
- `interface/gotobox.gui:67`：原版搜索窗口输入框，控件名`edit`。
- `common/button_effects/example.txt:2`：脚本按钮的This是选中对象或玩家国家，From为玩家国家；
  例子提供potential/allow/effect，没有给出输入框内容、字符串变量或文本变化回调。
- 当前导出的`effects.log`、`triggers.log`中未找到通用editbox读取或任意舰队名称子串匹配接口。
  `set_name`用于改名，不代表它能读取另一个输入框；显示用`GetName`也不等于字符串筛选。
- 已安装的1623423360界面模组有大量editBoxType，但检查到的是原版窗口覆盖用例，
  不能据此证明自定义事件可以读取输入内容。
- 已安装的3171051580模组`interface/grump_country_panel.gui:299`附近实现数字输入面板，
  通过每个数字的effectButtonType分别调用脚本；这与任意键盘文本回传不同。
- 伞框架相关GUI和脚本中本轮未发现自定义文本输入回传用例。

官方站点/论坛搜索没有得到足以确认Stellaris当前自定义文本回传接口的相关资料，
不将其他P社游戏的接口或无关论坛结果作为证据。

## 搜索功能仍缺的验证

1. 找到明确的界面→脚本文本传递机制，并可重复地将输入值显示或记录出来。
2. 验证中文、英文、空输入、修改输入和关闭重开；确保输入不被当作脚本执行。
3. 再验证对动态舰队名称的匹配能力和过滤后翻页的稳定性。

只有三步具备依据并通过实机验证，才能称舰队名称搜索可用。不凭空添加未记录的GUI属性，
也不为验证输入而注入、修改游戏执行文件。

## 不依赖自由文本的方向（未在本轮实现）

每页更多条目、首页/末页、只看已保护、按设计筛选、按钮式数字跳页。
另一个可验证方向是在选中舰队界面提供保护按钮：原版按钮文档明确支持选中舰队作用域，
可能减少回到名单翻页的次数，但仍需独立布局与原生作用域验收。

## 2026-10-17再次核查（整理工具0.2.4之后）

用户提出尝试搜索后，再次核查本机原版GUI、已安装创意工坊GUI、按钮效果示例，
以及本轮游戏重新导出的effects／triggers文档。仍未找到可复现的
“自由文本输入→脚本字符串→动态舰队名称子串筛选”调用链。
本轮未做游戏内输入实验，也未添加输入框或修改整理工具0.2.4。

补充证据：

- `localisation/simp_chinese/main_2_l_simp_chinese.yml:3575`中，原版
  `GOTOBOX_DESC`明确为“搜索已知恒星系”。不能将gotobox直接当作舰队搜索接口。
- 创意工坊扫描使用真实控件声明`^\s*editBoxType\s*=\s*\{`，
  避免将注释里提及控件名当成有效控件。
  `2982710154/interface/honkai_star_extend_planet_ui.gui:267,278`只是在注释里说明
  `text_color_code`的支持范围，没有声明输入框，也没有输入绑定或回传示例。
- 原版`common/button_effects/example.txt`明确给出选中对象This和玩家From，
  未提供输入框字符串作用域或读取函数。显示对象`GetName`只证明能显示对象名，
  不能据此推导可以读取独立输入框，也不能推导可以做名称子串比较。
- 在本机脚本导出文档中，仍未找到通用文本读取或动态名称子串判断的明确命令。
  外部检索也未取得可以照着实现并复测的Stellaris文本回传用例。

下一步实验必须先有一个明确的候选回传机制，再做只回显输入的最小GUI。
验收仍为中文／英文输入、清空、更改、关闭重开，并检查读取结果与输入逐字一致。
在候选机制未明确前，不凭空增加`GetText`、`on_text_changed`等未经本游戏证实的属性，
也不把可编辑的外观当作搜索功能完成。
