# 1.3.0 · 中枢界面更新

## 更新内容

- 首页使用紧凑双列分组入口，统一各功能面板的深色底板、标题和底栏。
- 精简常驻文字，将操作规则与功能解释移入悬浮提示，保留状态、费用预览和清空确认。
- 军事、星球经济、巨构资源设置页采用独立数值行；内阁管理区分日常设置与维护工具。
- 飞升槽位目标新增 ±2、±4、±16，结合原有 ±1、±8，共五档；调整后点击“补齐至目标”生效，目标范围 1～4096。
- 修复精简文字时引入的同化／飞升窗口引用错误，新增窗口引用打包校验和回归检查。
- 保留已有加成、目标及存档变量；降低飞升目标不会收回已经解锁的槽位。

## 安装与范围

适用于 Stellaris 4.5.*，简体中文。更新后完整退出并重启游戏；法令“打开星政中枢”进入。

公开版只收录游戏本体及官方 DLC 的内阁席位，无第三方 Mod 硬依赖，不覆盖原版内阁界面。飞升槽位补齐不扩展传统界面的格数，需按槽位 Mod 实际提供的格数调整目标。
