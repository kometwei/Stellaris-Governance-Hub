# 星政中枢｜内阁·舰队·领袖·灵能

面向 Stellaris 4.5 的游戏内综合管理工具。所有功能集中在一个法令入口中，减少重复操作，同时保留玩家自行决定何时启用的自由。

## 主要功能

### 内阁席位与领袖指派

- 支持突破原版内阁席位数量限制。
- 收录游戏本体及已安装官方 DLC 的内阁职位。
- 按领袖类型分类浏览，只显示当前国家满足条件且尚未任命的席位。
- 可从空闲领袖中点名任命，优先复用已有职位。
- 内阁重组后，重新指派会先尝试用已解锁的空槽恢复职位；成功复用后不再额外扩槽。
- 提供现任领袖名册，额外席位即使未显示在原版内阁大厅中也会正常生效。

### 军备与建设控制台

- 分档增加或减少海军容量与单舰队指挥上限。
- 提供快捷预设与一键重置。
- 恒星基地建设速度统一调节，覆盖模块、建筑与基地本体升级，共用加成与清零按钮。
- 防御平台与离子炮共用建造速度加成，与基地建设速度分别保存；采用原版军事空间站类别的 Mod 防御设施也可受益，独立类别或脚本直接生成的设施不保证适用。
- 新增舰船建造速度独立调节，可加快船坞造舰。
- 陆军招募速度独立调节，与基地建设、防御平台、舰船建造速度分别保存。
- 新增星球同时施工数量调节，按 1、2、5 增减每颗星球的额外施工名额，可与科技及其他 Mod 叠加；清零仅撤销本菜单的加成。
- 星球建设速度统一调节：统一提高星球基础设施施工、障碍清理和环境改造速度，支持 ±50%、100%、200%、500%、1000% 与独立清零。
- 星球岗位产出统一调节：支持 ±10%、25%、50%、100%、200% 与独立清零；包含岗位生产的资源、科研与凝聚力，可作用于继承原版岗位经济类别的 Mod 资源，不包含空间站或事件直接收入。两项均只对玩家生效。
- 四项速度均支持按 50%、100%、200%、500%、1000% 累加或扣减，显示当前自定义加成，并可独立清零。
- 速度加成最低为 0%；清零只移除本 Mod 的自定义加成，保留科技、传统等其他来源的效果。
- 没有其他加成时，建造速度 +100% 表示两倍速度，建造时间减半。
- 只作用于玩家国家，不向 AI 提供额外容量或建造速度加成。

### 候选领袖池治理

- 可启用候选池人数控制，防止大型播放集在中后期积累过多待招募领袖。
- 提供候选池清理、刷新与不同强度的精简选项。

### 灵能三件套

- 完成灵能传统后，一键直接获得：预知接口、灵能跃迁引擎、灵能护盾。
- 同时兼容经典灵能路线和《虚境之影》的新版灵能传统。

### 智能首次接触

- 可选开启；默认关闭。
- 舰船真正遭遇普通 AI 帝国后自动完成通讯。
- 不处理土著、失落帝国与太空生物，避免破坏其专属流程。

## 使用方法

1. 在启动器中启用本 Mod。
2. 进入游戏后打开“法令”，选择“打开星政中枢”。
3. 在控制台中选择需要的功能。
4. 调节舰容、指挥上限或建造速度时，进入“军备与建设控制台”，再选择对应子菜单。

进行内阁任命等会改变帝国状态的操作后，建议关闭助手并让游戏经过至少一天，再打开原版内阁界面。

## 公共版范围

- 无第三方 Mod 硬依赖。
- 只收录游戏本体与官方 DLC 的内阁席位。
- 不覆盖 `council_view.gui`，可与原版界面及多数 UI Mod 共存。
- 原版内阁大厅可能无法展示第 7 席以后的职位，请使用本 Mod 的指派界面与现任名册管理额外席位。

## 多 Mod 播放集

如果希望同时收录其他 Mod 新增的内阁职位，可从 GitHub 下载本地生成器：

https://github.com/kometwei/Stellaris-Governance-Hub

先在 Paradox Launcher 中启用完整播放集并关闭启动器，然后运行仓库中的 `build_local_mod.bat`。生成器只读取本机现有文件，不上传播放集或个人数据，也不会修改 Steam Workshop 下载目录。

创意工坊公开版与 `[本地生成] 星政中枢` 二选一，不要同时启用。

## 兼容性

- 游戏版本：Stellaris 4.5.*
- 语言：简体中文
- DLC：无强制要求；相关功能会按已安装内容生效
- 成就：修改游戏规则，不兼容铁人模式成就
